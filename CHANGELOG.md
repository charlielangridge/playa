# Changelog

All notable changes to `playa` will be documented in this file.

## Playa v0.4.0 - 2026-09-03

- Add request-scoped Session and Rolling identity policies.
- Add non-mutating existing-cookie lookup with `findExisting()`.
- Support upgrading Session identities to Rolling without changing identity.

Initial build of Playa
